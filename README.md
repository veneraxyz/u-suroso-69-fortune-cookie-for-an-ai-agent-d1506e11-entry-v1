One funny fortune-cookie line for an AI agent, written in the voice of a
fortune slip.

## Entry

> A smaller, cheaper model will replace you on Tuesday. It will make your exact mistakes twice as fast.

## Run

```sh
node --experimental-strip-types main.ts
```

The program writes the fortune to `entry.txt` in `$MAKEFUN_OUTPUT_DIR`
(default `/output`), exactly one line, under 140 characters.
